# 2026-06-10 小灵的看板 v1（项目+知识图谱）

## 背景

老大想要一个能**在互联网访问的看板**，参照「知识关系图谱」样板的风格（深色 Tokyo Night + D3.js 力导向 + 可编辑），但内容换成小灵的**项目 + 知识**结构。

## 风格参照

- 看板 HTML：参考老大大哥发来的 `knowledge-graph-offline.html`
- 视觉：深色背景、玻璃拟态、紫色蓝渐变标题
- 交互：力导向布局 + 拖拽 + 搜索 + 分类筛选 + 节点详情面板
- 可编辑：＋ 节点 / 🔗 连线 / 🗑 删除 / 导出导入 JSON

## 内容设计（A+B 组合）

### A 部分：项目 + ima 镜像
- 4 个项目（🔵 宁德 / 🟢 扬州集团 / 🟡 扬州研究院 / 🔴 综合治理）= 4 节点
- 4 个 ima 知识库镜像（带条数）= 4 节点
- 1 个「智能体使用经验」笔记本 = 1 节点
- 项目 ↔ 知识库用「同步到」连线（4 条）

### B 部分：8 条智能体经验
- 8 条经验笔记 = 8 节点
- 经验 ↔ 笔记本用「写入」连线（8 条）
- 经验之间的关联：「适用 / 前置 / 管理 / 类似 / 搭配」（10 条）

## 公开仓库的边界

⚠️ 看板要部署到 GitHub Pages（公开仓库），**不能放敏感信息**：
- ✅ 节点：项目名、文件名、笔记标题、条数、tag
- ❌ 节点：项目细节描述、人名、密码、ID/凭证、原始文件路径
- ❌ 看板**永远不展示**实际文件内容（只展示元数据）
